# 教师工作台对话详情与产物预览设计

## 1. 背景与目标

教师工作台已经采用浅色点阵背景、红色品牌强调色、圆角白色卡片和轻量阴影。当前工作台生成入口仍跳转到旧版 `/common-chat`，页面结构与视觉风格不一致，且 Mock 对话只能返回通用文本，无法展示技能调用过程与可预览的教学产物。

本次改版目标：

1. 新增教师专用对话详情页 `/teacher/workspace/chat`，复用教师端全局导航和工作台视觉语言。
2. 支持课纲、教案、研究、幻灯片、测验、实训等技能的 Mock 调用记录与结果展示。
3. 幻灯片、测验和实训三类生成结果提供可交互预览。
4. 保持纯前端 Mock，不连接后端，不影响学生端及其他仍使用 `/common-chat` 的入口。

## 2. 范围与边界

### 本期包含

- 教师工作台到新对话页的路由与技能参数传递。
- 对话历史、消息流、技能运行轨迹、产物列表和输入区。
- 幻灯片、测验、实训预览弹窗。
- Mock 对话与产物数据、浏览器本地状态。
- 桌面、平板和窄屏布局。
- 键盘焦点、语义标签、弹窗焦点管理及动态状态播报。

### 本期不包含

- 真实大模型、工具或后端接口调用。
- PPTX、Word、PDF 等真实文件导出。
- 多人实时协作和云端会话同步。
- 学生端 `/common-chat` 的视觉重构。

## 3. 页面路由与信息架构

### 路由

- 工作台：`/teacher`
- 教师对话详情：`/teacher/workspace/chat?text=<任务>&skills=<技能列表>`
- 旧通用对话：`/common-chat`，保持原样供其他入口使用。

### 页面结构

```text
教师端全局导航
└── 对话详情工作区（点阵浅底）
    ├── 左侧：对话历史
    ├── 中间：任务标题、消息流、技能调用轨迹、输入器
    └── 右侧：本次生成产物
        ├── 幻灯片
        ├── 随堂测验
        └── 实训工单
```

## 4. 视觉设计

- 背景：沿用工作台 `#FAFBFC` 与 24px 点阵纹理。
- 主色：`#C8000B`；浅强调背景：`#FFF1F0`。
- 正文：`#0F172A`；次级文本：`#64748B`；边框：`#E2E8F0`。
- 卡片：白底、14–18px 圆角、细边框、低饱和阴影。
- 消息：教师消息使用浅红气泡；AI 消息使用白色卡片，不再使用旧版大面积背景图。
- 技能轨迹：以紧凑步骤条展示“准备—调用—完成”，不同技能使用图标和轻量色彩区分，完成态统一使用绿色状态点。
- 产物卡片：显示类型、标题、生成摘要、页数/题数/步骤数和“预览”主操作。

## 5. 响应式规则

- `lg` 及以上：三栏布局，历史栏约 248px，产物栏约 320px，中间栏自适应。
- `md`：隐藏历史栏，提供“历史会话”抽屉按钮；产物栏缩为 280px。
- `base`：仅保留消息主栏；历史与产物均通过抽屉/弹窗访问，输入器固定在底部。
- 所有核心触控目标不小于 40px；内容在 200% 缩放下保持可滚动。

## 6. 技能模型与调用展示

### 支持技能

| 技能键 | 展示名称 | Mock 输出 |
| --- | --- | --- |
| `outline` | 课纲解析 | 课程目标、重难点、标准对齐摘要 |
| `lesson` | 教案编写 | 45 分钟教学流程与板书结构 |
| `research` | 深度研究 | 行业案例与近年教学趋势摘要 |
| `slides` | 幻灯片生成 | 可预览的 6 页示例课件 |
| `quiz` | 随堂测验 | 可作答、提交和查看得分的示例测验 |
| `practice` | 实训设计 | 可勾选步骤、查看安全提醒和评价表的实训工单 |

### 工作台参数映射

- 课纲智能解析 → `outline`
- 教案自动编写 → `lesson,slides,quiz`
- 课堂实训互动 → `practice,quiz`
- 专业图谱乐享 → `research`
- 快捷能力会向当前技能集合追加对应技能。
- 未明确选择技能时，根据输入关键词推断；无法推断时默认生成 `lesson,slides,quiz,practice` 完整课包。

### 调用轨迹

每次教师发送任务后，消息流插入一张技能运行卡：

1. 解析教学目标与约束。
2. 按技能顺序展示 Mock 工具名称、摘要、耗时和完成状态。
3. 生成总结果说明和产物卡片。
4. `aria-live="polite"` 播报技能完成与产物就绪状态。

## 7. Mock 数据结构

核心类型：

```ts
type WorkspaceSkillKey =
  | 'outline'
  | 'lesson'
  | 'research'
  | 'slides'
  | 'quiz'
  | 'practice';

type MockSkillInvocation = {
  id: string;
  skill: WorkspaceSkillKey;
  title: string;
  summary: string;
  status: 'queued' | 'running' | 'completed';
  durationMs: number;
};

type MockArtifact =
  | { type: 'slides'; payload: MockSlideDeck }
  | { type: 'quiz'; payload: MockQuiz }
  | { type: 'practice'; payload: MockPracticeSheet };
```

Mock 生成器使用确定性模板，根据任务文本和技能列表生成：

- 教师消息。
- AI 概要回复。
- 技能调用轨迹。
- 对应产物。

对话历史与最新任务可保存在浏览器 `localStorage`，不发送到网络。

## 8. 三类产物预览

### 幻灯片预览

- 大尺寸弹窗。
- 左侧 6 页缩略图，右侧当前页主画布。
- 支持上一页、下一页和直接选择页码。
- 示例内容包含封面、学习目标、原理图解、操作步骤、安全规范和课堂总结。

### 测验预览

- 展示 3–5 道单选题。
- 支持选择答案、提交、即时得分、答案解析和重新作答。
- 未作答题目在提交前给出提示。

### 实训内容预览

- 使用“任务说明 / 操作步骤 / 评价标准”三个页签。
- 操作步骤支持逐项勾选，显示完成进度。
- 安全事项使用高对比提示卡。
- 评价标准展示教师评分维度与分值。

## 9. 交互与可访问性

- 所有图标按钮提供 `aria-label`。
- 技能选择使用 `aria-pressed`。
- 弹窗使用 Chakra Modal 管理焦点、Esc 关闭和焦点回归。
- 页签使用 Chakra Tabs，支持键盘方向键切换。
- 所有操作保留可见焦点环。
- 尊重 `prefers-reduced-motion`。
- 窄屏历史与产物入口提供明确文字标签，不依赖纯图标识别。

## 11. 测试示例

1. URL 能正确编码任务文本和多个技能。
2. 技能列表去重并过滤非法值。
3. 输入包含“PPT / 幻灯片”时能推断 `slides`。
4. 输入包含“测验 / 试题”时能推断 `quiz`。
5. 输入包含“实训 / 工单”时能推断 `practice`。
6. 幻灯片产物至少包含 6 页并具备唯一页码。
7. 测验产物包含正确答案与解析。
8. 实训产物包含任务目标、步骤、安全事项与评价维度。
9. 工作台入口携带的技能参数能在详情页展示对应调用轨迹。
10. 三类产物预览均可打开、交互并关闭。

## 12. 验收标准

- 从教师工作台发起任务后进入新详情页，视觉风格与工作台一致。
- 对话中可看见实际调用了哪些 Mock 技能，以及每个技能的状态和结果摘要。
- 选择不同技能并发送后，产物内容和调用轨迹随之变化。
- 幻灯片、测验、实训卡片均可进入完整预览并完成核心交互。
- 全流程不产生后端请求。
- 原学生端和旧 `/common-chat` 路径不受影响。
- Vitest、目标 ESLint 与 Next.js 生产构建通过。

## 13. 2026-09-09 输入器交互调整

### 场景入口

- 工作台场景只保留“实训工单”和“日程备课”，移除“开始”和“任务管理”。
- 切换场景时同步替换默认技能：“实训工单”默认选择 `practice`，“日程备课”默认选择 `lesson`。

### 单技能约束

- 每次任务最多选择一个技能；点击能力卡片、快捷能力或技能菜单时，新技能直接替换旧技能。
- Mock 执行器即使收到旧链接中的多个技能，也只执行第一个有效技能，保证历史参数兼容且不恢复多选。
- 当前技能在输入框内容区显示为可删除标签。

### 输入上下文

工作台与对话详情页输入框左下角统一提供：

1. 上传文件：支持多文件选择，文件名作为可删除标签显示。
2. 模式：提供“计划”和“仅问答”，当前模式作为可删除标签显示；“仅问答”仍调用所选技能，但不生成扩展产物。
3. 选择技能：六种技能单选，当前技能作为可删除标签显示。
4. 选择专家：提供职教课程、行业实践、教学评价和课件视觉四类 Mock 专家，当前专家作为可删除标签显示。

移除旧的“Craft 模式”“Auto 引擎”“备课技能”及多智能体流水线入口。详情路由改为单技能上下文参数：

```text
/teacher/workspace/chat?text=<任务>&skill=<技能>&mode=<模式>&expert=<专家>
```

对话消息保留发送时的技能、模式、专家和附件快照，便于演示不同上下文的 Mock 结果。

## 14. 2026-09-09 场景技能与全产物 Mock

### 场景技能

- 日程备课：`lesson` 教案生成、`slides` PPT 制作、`interactive` 互动课件、`video` 视频课件、`quiz` 随堂诊断与测验。
- 实训工单：`practice` 互动实训设计、`standards` 技能标准对齐。
- 场景切换后，技能菜单只展示该场景允许的技能，并选中该场景的默认技能。
- 选择技能时，输入框内容同步替换为该技能的任务模板；从能力卡片或快捷标签选择跨场景技能时，同步切换场景。

### 输入器样式

参考 WorkBuddy 的紧凑输入器语言：上传文件使用轻量图标入口，模式、技能、专家使用无重边框的紧凑菜单按钮；选择结果在文本区域上方以带图标的轻量标签回显。菜单显示当前值、场景分组标题和单选勾选状态，回显标签均可独立删除。

### Mock 产物

七个技能均生成一项可预览 Mock 产物：

| 技能 | Mock 产物 |
| --- | --- |
| 教案生成 | 教学目标、课堂时间轴、板书与评价方案 |
| PPT 制作 | 6 页可翻页课件 |
| 互动课件 | 互动模块、反馈机制与课堂投放状态 |
| 视频课件 | 视频画面、时长、分镜章节与字幕摘要 |
| 随堂诊断与测验 | 可作答、评分和查看解析的测验 |
| 互动实训设计 | 任务、步骤、安全事项与评价量规 |
| 技能标准对齐 | 标准编码、能力点、证据与覆盖率 |

“仅问答”模式仍只返回文本结论，不生成产物；切回“计划”模式后按当前技能生成对应产物。
