## 1. 目标

教师可围绕课程章节与知识点维护题目：手动出题、AI 出题，按章节浏览题目列表，支持编辑与删除。

## 2. 题型与数据模型（mock 层）

```ts
type QuestionType = 'single' | 'multiple' | 'judge' | 'blank' | 'essay'; // 单选/多选/判断/填空/简答
type QuestionDifficulty = 'easy' | 'medium' | 'hard';
type QuestionSource = 'manual' | 'ai';

type Question = {
  id: string;
  type: QuestionType;
  stem: string;                    // 题干
  options: { key: string; text: string }[]; // 单选/多选选项
  answer: string[];                // 单选 ['A']；多选 ['A','C']；判断 ['正确'|'错误']；填空各空答案；简答参考答案
  analysis: string;                // 解析
  difficulty: QuestionDifficulty;
  chapterId: string;               // 关联章/节（与章节树节点 id 一致）
  chapterTitle: string;            // 冗余标题，列表展示用
  knowledgePoints: string[];       // 关联知识点名称
  source: QuestionSource;
  createdAt: string;
};
```

- 章节树直接复用 `avatarDetail.chapterList`（与知识图谱同源，保证原型一致性）。
- 知识点来源：所选章节的 `knowledgePoints`；章节无知识点时允许手动输入自定义知识点标签。

## 3. 页面结构

```
┌ 题库管理 ──────────────────────────────── [AI 出题] [手动出题] ┐
│ 统计条：题目总数 / AI 出题 / 手动出题 / 覆盖章节                │
├──────────────┬───────────────────────────────────────────────┤
│ 章节树        │ 题型筛选 chips（全部/单选/多选/判断/填空/简答） │
│ 全部题目(N)   │ 题目卡片列表：                                 │
│  第一章 (2)   │  [题型][难度][来源] 题干                       │
│   第一节 (1)  │  选项/答案预览                                 │
│  第二章 (3)   │  所属章节 · 知识点标签 · 时间   [编辑] [删除]   │
└──────────────┴───────────────────────────────────────────────┘
```

- 章节树节点带题目数徽标；选中章时含其所有小节的题目。
- 删除走二次确认（AlertDialog）。

## 4. 手动出题（编辑共用）

Modal 表单：题型切换（5 种 segmented）→ 按题型渲染答题区：

- 单选/多选：选项编辑器（增删选项、点选正确答案）
- 判断：正确/错误二选一
- 填空：答案列表（每空一条，可增删）
- 简答：参考答案是文本域

公共字段：题干、解析、难度、所属章节（树形下拉）、关联知识点（章节知识点 chips 多选 + 自定义输入）。

## 5. AI 出题（模拟）

1. Modal 内选择：章节、知识点（多选 chips）、各题型数量（stepper 0-5）、难度
2. 「开始生成」→ loading ~1.5s（模拟）→ 模板化生成题目预览
3. 预览列表可勾选/取消，「加入题库(N)」落库到内存态，source='ai'

## 6. 交互与边界

- 全部状态存于 Tab 组件内 useState；Chakra Tabs isLazy 挂载后不卸载，切 tab 不丢状态；刷新页面即重置（原型语义）。
- 题干/答案必填校验；单选必须且仅一个正确项，多选至少一个。
- 空态：章节无题目时显示空提示 + 引导出题按钮。
- 本 Tab 内 UI 文案暂用硬编码中文（与 TabMindmap 一致）；tab 标签走 i18n（`avatar.detail.tabs.questionBank`，三语）。正式接入时再整体收口 i18n。

## 8. 第二轮增强（2026-09-04）

### 8.1 填空题填空标识

- 题干用 `【1】【2】…` 标记填空位置；编辑弹窗提供「＋ 插入填空标识」按钮（仅填空题型显示），点击后在光标处插入下一序号标识并同步补齐答案行。
- 答案区实时提示已标记空数（0 个空时改为引导文案），答案按空号顺序对应；提交校验：无标识 / 标识数与答案数不一致均阻断并 toast 提示。
- 列表渲染：`StemRichText` 将 `【n】` 转为橙色高亮标记（orange.600 / orange.50）。

### 8.2 关联知识点 mock 数据

- `mockData.mockKnowledgePoints(title)` 按章节标题派生 3 个 mock 知识点（基本概念/核心要点/应用实例）；章节树构建时对缺知识点的节点自动填充，编辑弹窗与 AI 出题弹窗的知识点 chips 均有可选数据，仍保留手动添加自定义知识点。

### 8.3 题目列表翻页

- 每页 5 题（`PAGE_SIZE`），页码条含「共 N 题」与上/下一页；筛选（章节/题型/关键词）变化自动回到第 1 页。

### 8.4 简答题评分标准

- `Question.gradingCriteria?: string`；简答题型显示「评分标准（AI 评价参考）」文本域，placeholder 引导文案：为AI评价提供参考依据，建议包含评分维度、权重分配、具体要求等。
- 列表卡片以紫色虚线块展示评分标准。

### 8.5 AI 题目可编辑

- AI 预览列表每条目提供「编辑该题」→ 嵌套打开 QuestionEditModal；保存就地更新预览（保留 `source: 'ai'`），入库后的 AI 题同样可经列表「编辑」修改。

### 8.6 公式编辑器与图片

- 题干支持 `$LaTeX$` 行内公式与图片：工具栏「∑ 插入公式」打开嵌套公式编辑器（LaTeX 输入 + 常用模板 chips + KaTeX 实时预览，确认后按光标位置插入 `$...$`）；「🖼 插入图片」走 FileReader → dataURL，题干插入 `![名称](img-id)` 引用，下方缩略图列表可删除（同步移除题干引用）。
- 渲染层 `StemRichText`（react-markdown + remark-math + rehype-katex，均为项目已有依赖）：题干内联渲染公式、图片（按 id/name 从 `Question.images` 解析 dataURL）与填空标识；编辑弹窗含公式/图片时显示效果预览框。
- 种子数据新增置顶展示题：正态分布公式 + 钟形曲线 SVG 图。

### 8.7 验证记录

- 浏览器实测通过：手动填空题全流程（插标识→填答案→创建→列表高亮）、图片上传与列表渲染、公式编辑器三层嵌套弹窗（AI 预览→编辑→公式）插入后仅关闭公式层、AI 预览编辑保存回路、简答评分标准字段、分页（14 题 3 页）。

## 11. 测验管理（2026-09-04）

### 11.1 功能定位与入口

- 教师端 AI 分身详情页在「题库管理」后新增「测验管理」Tab（i18n：zh-CN 测验管理 / zh-Hant 測驗管理 / en Quizzes）。
- 列表统计条：测验总数 / 已发布 / 草稿 / 累计题目；右侧「创建测验」按钮。
- 测验卡片：状态 badge（草稿灰 / 已发布绿）、标题、描述、发布班级 chips、截止时间（过期红色 + 「已截止」badge）、题数·总分、创建时间；操作：查看（只读详情）/ 编辑（仅草稿）/ 发布（仅草稿）/ 删除（二次确认 AlertDialog）。
- 种子数据：1 个已发布（产品设计概述随堂测验，第一章 3 题 100 分）+ 1 个草稿（阶段复习测验，带 pushConfig 保证编辑回填）。

### 11.2 创建/编辑测验（QuizWizardModal 两步向导）

- Step 1「基本信息与推题」：标题*、描述、发布班级*（chips 多选，取 avatarDetail.classList，空时回退 mock 4 个班）、截止时间*（datetime-local，默认 7 天后 23:59，maxW 240px 防止无头浏览器固有宽度过大）、总分（NumberInput 默认 100）；推题方式二选一：按章节（章节 checkbox 列表，全角空格缩进）/ 按知识点（复用 KpTreePanel 树多选）；题型数量 stepper（五题型 0-20）。
- Step 2「预览与调分」：汇总行「共 N 题 · 合计 X 分（目标 Y 分）」，不一致时橙色提示；题目行 = 序号 + 题型 badge + 章节 + StemRichText 题干（公式/图片）+ 分值 NumberInput + 删除；「从题库选题」打开 QuestionPickerModal（章节下拉 + 关键词搜索 + 多选，已添加题 disabled + tag，新选题默认 5 分）；底部「上一步 / 保存草稿 / 发布测验」。
- 推题：`pickQuestionsFromBank`（按章节含子节 / 按知识点过滤题库后按题型截取数量，不足按实际数量）；`distributeScores` 目标总分均分（余数前补，题数超总分保底 1 分）。
- 编辑回填：pushConfig 全量回填；`normalizeConfig` 规范化 JSON 对比（counts 按题型序生成键值对数组），配置未变时下一步保留已调整题目，变更才重新推题。
- 校验：标题/班级/截止时间必填；推题数>0 时必须选章节或知识点；发布时至少 1 题；0 命中允许继续并 toast 提示手动选题。

### 11.3 状态提升与数据共享

- 题库章节树与题目列表提升到 page.tsx（`questionChapterTree` + `bankQuestions`），TabQuestionBank 改为受控 props（`chapterTree / questions / onQuestionsChange`），测验管理读取同一题库；章节异步加载后惰性播种（题目与种子测验各一次，ref 防重）。
- 测验题目为题库题目快照（`QuizQuestionItem { question, score }`），题库后续修改不影响已组卷测验。

### 11.4 关键坑：主题 Modal size="xl" 强制 body 宽 1124px

- FastGPT 基础主题 `packages/web/styles/theme.ts` 中 `Modal.sizes.xl = { body: { w: '1124px' } }`，且 dialog `overflow: hidden`：xl 弹窗 body 被强行撑到 1124px 并被 dialog 裁切，表现为内容右半截被切、flex 行溢出。本项目弹窗禁用 `size="xl"`，统一用 `2xl`/`3xl`。

### 11.5 验证记录

- 浏览器实测通过：种子列表统计与卡片渲染；创建全流程（标题/班级/截止/总分 → 按章节勾第一章 → 下一步推 3 题 34/33/33 → 改分值 40 → 删除一题 → 从题库选题加 1 题默认 5 分 → 发布，列表新增已发布卡片、统计刷新）；按知识点模式树面板渲染；草稿编辑回填（章节勾选 + 下一步保留 3 题 60 分不清空）；查看弹窗（3xl 正常，公式/图片/分值展示）；删除二次确认；控制台无报错。
