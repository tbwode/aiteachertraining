# 导出学生数据功能实现说明

## 功能概述

为 AI 分身详情页的学生管理标签页添加了导出功能,支持将学生数据导出为 Excel 文件,并支持按班级筛选导出。

## 实现内容

### 1. API 接口 (`src/teacher/api/aiTeacher.ts`)

添加了 `exportAvatarStudents` 接口:

```typescript
/**
 * 导出AI分身学生数据
 */
export const exportAvatarStudents = (data: {
  avatarId: number;
  clazzId?: number | null;
  progressRange?: string | null;
  status?: number | null;
  isLagging?: number | null;
  searchKey?: string | null;
}): Promise<Blob> =>
  POST('/client/aiTeacher/avatars/students/export', data, {
    baseURL,
    responseType: 'blob'
  });
```

**参数说明:**
- `avatarId`: AI分身ID (必需)
- `clazzId`: 班级ID (可选,null或0表示全部班级)
- `progressRange`: 进度范围 (可选,用于筛选进度区间)
- `status`: 学习状态 (可选,0-未开始,1-学习中,2-已完成)
- `isLagging`: 是否滞后 (可选,0-否,1-是)
- `searchKey`: 搜索关键字 (可选,学生姓名或学号)

## 功能特性

### 1. 班级筛选支持 ✅
- **全部班级**: 当选择"全部班级"时,`clazzId` 传递 `null`
- **特定班级**: 当选择具体班级时,自动查找对应的班级ID并传递
- **班级映射**: 通过 `classNameToIdMap` 实现班级名称到ID的映射
- **日志输出**: 导出时会输出选中的班级名称和对应的ID,便于调试

### 2. 其他筛选条件
- **搜索关键字**: 支持按学生姓名/学号搜索
- **进度范围**: 预留接口,可扩展
- **学习状态**: 预留接口,可扩展
- **滞后状态**: 预留接口,可扩展

### 3. 用户体验优化
- **加载状态**: 导出过程中按钮显示"导出中"状态
- **错误处理**: 完善的错误提示和异常处理
- **成功反馈**: 导出成功后显示 Toast 提示
- **自动下载**: 导出完成后自动触发文件下载
- **调试日志**: 输出导出参数和班级映射信息

### 4. 文件命名
导出的文件名格式: `学生数据_时间戳.xlsx`

## 技术实现细节

### 班级ID映射逻辑
```typescript
// 1. 创建映射表
const classNameToIdMap = new Map<string, number>();
allStudents.forEach((student) => {
  if (student.className && student.classId !== null) {
    map.set(student.className, student.classId);
  }
});

// 2. 导出时查找班级ID
let clazzId: number | null = null;
if (selectedClass !== 'all') {
  clazzId = classNameToIdMap.get(selectedClass) ?? null;
}

// 3. 传递给API
const exportParams = {
  avatarId: Number(avatarId),
  clazzId: selectedClass === 'all' ? null : clazzId, // null表示全部班级
  searchKey: searchText || null
};
```

### Blob 响应处理
```typescript
// 1. API 调用返回 Blob
const blob = await exportAvatarStudents(exportParams);

// 2. 创建下载链接
const url = window.URL.createObjectURL(blob);
const link = document.createElement('a');
link.href = url;
link.download = `学生数据_${new Date().getTime()}.xlsx`;

// 3. 触发下载
document.body.appendChild(link);
link.click();

// 4. 清理资源
document.body.removeChild(link);
window.URL.revokeObjectURL(url);
```

### 请求配置
`requestTeacher` 工具已支持 `responseType: 'blob'`,会自动:
- 跳过 JSON 响应校验
- 直接返回 Blob 数据
- 保持完整的二进制数据

## 数据流程

```
用户选择班级 → selectedClass
         ↓
   classNameToIdMap.get(selectedClass)
         ↓
      clazzId (number | null)
         ↓
   exportAvatarStudents({ avatarId, clazzId, ... })
         ↓
   后端根据 clazzId 筛选数据
         ↓
   返回 Excel 文件 (Blob)
         ↓
   前端触发下载
```
